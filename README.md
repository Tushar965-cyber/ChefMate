# ChefMate

ChefMate is an AI-powered offline recipe matching tool.

## Project Structure
- `frontend/`: The React frontend application (Vite).
- `data/`: Contains `recipes.json` dataset.
- `model/`: Trained ML files for intent classification.
- `app.py`: Backend server logic.
- `templates/` & `static/`: Python backend web assets.

## Running
To start the backend:
`python app.py`

To start the frontend:
`cd frontend`
`pnpm install`
`pnpm run dev`
